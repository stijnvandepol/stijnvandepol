## 🧪 The homelab

```text
homelab/
├── proxmox/              # the foundation: VMs + LXC containers
│   ├── docker/           # most of my apps live here
│   └── backups/          # automated, because I learned the hard way
├── dtap/                 # dev → test → acceptance → prod, deployed by GitHub Actions
├── cloudflared/          # no open ports, just tunnels
├── monitoring/           # Beszel + Checkmk, alerts before things go down
├── automation/           # n8n workflows + AI agents talking over MCP
└── azure/                # hybrid: Intune & cloud identity next to on-prem
```
